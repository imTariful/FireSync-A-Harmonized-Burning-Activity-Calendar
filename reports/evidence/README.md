- temporal holdout 6 training / 3 validation cells, R² `null`;

These numbers are preserved for history only. Current live-world diagnostics are in
`reports/remediation/SCIENTIFIC_VALIDATION_REPORT.md`.

## Rules for reading these files

1. R² `0` in a legacy file means "undefined, stored as zero" only when the reference
   variance is zero. The current UI/report displays `null`.
2. "GLM", "fitted", "empirical scale" or "validated" labels in legacy files are not
   evidence that a model was fitted or validated.
3. A SHA-256 checksum proves the bytes match the recorded digest. It does not prove NASA
   authenticity.
4. No number here should be quoted as a Bangladesh calibration coefficient.

See `reports/remediation/SCIENTIFIC_VALIDATION_REPORT.md` and
`reports/remediation/PROVENANCE_REPORT.md` for the authoritative current interpretation.
